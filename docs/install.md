# Установка на часы и симулятор

Источники: docs.zepp.com (guides/quick-start/preview, guides/tools/zepp-app, guides/tools/cli,
guides/tools/simulator/download, guides/faq/simulator-faq) и README `@zeppos/zeus-cli` 1.10.2.

## Подготовка на компьютере

Для сборки используй Bash, Git, запущенный Docker с Compose и `just`. Node.js, npm и Zeus входят в Docker-образ. Скопируй HTTPS-адрес репозитория через **Code → HTTPS** на GitHub и подставь его вместо `<URL>` в первой команде.

```bash
git clone <URL> amazfit-watchfaces
cd amazfit-watchfaces
docker compose version
just --version
just install
```

Остальные команды выполняй из этого каталога. Чтобы проверить сборку до входа в аккаунт, выполни `just build`. Пакет появится в `faces/segment/dist/`. Команда `just mock` сохранит макет основного экрана и AOD в `faces/segment/mock/preview.png`.

## 1. Телефон: аккаунт Zepp и привязка часов

Скорее всего, у тебя это уже сделано.

1. Установи приложение **Zepp** (Google Play / App Store).
2. Зарегистрируйся или войди в **аккаунт Zepp**.
3. Привяжи Amazfit Active Max по подсказкам приложения.

## 2. Телефон: режим разработчика

Zepp → **Профиль** → **Настройки** → **О приложении** → нажми на иконку Zepp **7 раз подряд**, пока
не появится всплывающее окно. После этого в Профиле у привязанных часов появится пункт
**Developer Mode / Режим разработчика** со сканером QR-кодов.

Выключить: Профиль → Настройки → убрать опцию Developer Mode.

## 3. Аккаунт разработчика (Zepp Open Platform)

Для входа используй свой аккаунт Zepp. Если сайт попросит завершить регистрацию разработчика, следуй подсказкам [Zepp Open Platform](https://developer.zepp.com/). Для SEGMENT предпросмотр на Active Max проверен с `appId` из репозитория.

## 4. Вход в Zeus через Docker

1. Выполни `just login` и оставь терминал открытым.
2. Открой выданную ссылку в браузере и войди в Zepp. После успешного входа адрес начнётся с `http://localhost:…/login/callback`. Браузер может показать ошибку подключения к localhost — в этом случае адрес уже можно скопировать.
3. Скопируй **весь** адрес перенаправления вместе с параметрами и вставь его в ожидающий терминал. Этот адрес содержит данные входа.
4. Выполни `just status`. При успешном входе Zeus покажет твой никнейм и ID. Статус симулятора `disconnected` допустим при установке на реальные часы.

Сессия хранится в Docker-томе `zepp-auth` этого проекта. При следующем запуске в том же каталоге достаточно `just status`. На новом компьютере или после удаления тома снова выполни `just login`.

Если ошибка появилась **на странице Zepp до перехода на localhost**, проверь в браузере запрос к `api-user.huami.com`. В нашей сети HTTPS-соединение с этим доменом зависало на этапе TLS. В таком случае попробуй повторить вход через другую сеть, например мобильную точку доступа.

## 5. Установка на часы

```bash
just preview segment
```

Если Zeus предложит выбрать устройство, стрелками выбери **Amazfit Active Max** и нажми Enter. После сборки в терминале появятся имя **SEGMENT**, QR-код и срок его действия. Дальше на телефоне:

1. Zepp → Профиль → твои часы → **Режим разработчика** → **Сканировать**.
2. Отсканируй QR с экрана. Циферблат загрузится на часы через телефон.
3. Часы должны быть рядом, с включённым Bluetooth, и подключены к Zepp.

Для следующей версии или после истечения срока QR снова выполни `just preview segment` и отсканируй новый код.

Если QR в терминале не сканируется (мелкий шрифт, тёмная тема), увеличь окно терминала или уменьши
масштаб шрифта.

Для локального предпросмотра у Zeus также есть `zeus preview --local`. В этом режиме телефон должен иметь доступ к HTTP-порту контейнера по локальной сети. Приведённая выше команда `just preview segment` использует облачный предпросмотр.

## 6. Что проверить на часах

- Время и секунды, переход минут.
- Для AOD выбери SEGMENT текущим циферблатом. На часах открой **Настройки → Дисплей → Always On Display**, включи режим и выбери стиль текущего циферблата. Опусти запястье и дождись экрана ожидания.
- Дата, день недели и месяц по-русски. Порядок дней недели (понедельник первым) пока не подтверждён.
- Погода (иконка и температура, в том числе отрицательная), заряд, шаги, калории, пульс, дистанция.
- Значок будильника появляется, только когда будильник включён.
- Тапы: пульс, шаги, калории, погода, будильник.

## 7. Симулятор (необязательно)

Нужен для быстрой проверки без часов. Ставится в WSL (Ubuntu 24.04, окно выводится через WSLg).

```bash
cd /tmp
curl -LO https://upload-cdn.zepp.com/zepp-applet-and-wechat-applet/20260717/simulator_2.1.2_linux_amd64.deb
sudo apt install ./simulator_2.1.2_linux_amd64.deb

# Ubuntu 24 (noble), из simulator FAQ
sudo apt-get install -y libcapstone4 libsdl2-dev libaio-dev
[ -e /usr/lib/x86_64-linux-gnu/libaio.so.1 ] || sudo ln -s /usr/lib/x86_64-linux-gnu/libaio.so.1t64 /usr/lib/x86_64-linux-gnu/libaio.so.1
sudo chmod 4755 /opt/simulator/chrome-sandbox
```

Запуск симулятора: `/opt/simulator/simulator` (или из меню). Внутри скачай эмулятор устройства:
Active Max, если он есть в списке, иначе любой круглый 480×480. Запусти его, затем:

```bash
npm run dev -w faces/segment
```

Не проверено: работа симулятора под WSLg и наличие профиля Active Max.
