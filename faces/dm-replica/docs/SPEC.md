# DM Replica — спецификация

Копия циферблата **DM** (автор larrabee777, Amazfit T-Rex 2) для Amazfit Active Max.
Некоммерческий проект: не публикуется в магазине Zepp, готовые `.zab` не распространяются. По первому
запросу автора копия удаляется. Общая архитектура описана в `../../docs/ARCHITECTURE.md`.

## Дизайн
- Обычный режим — **копия DM один в один**: компоновка, размеры, цвета и шрифт как в оригинале.
- Своё рисуем только для иконок (погода, будильник, молния, огонь, следы, сердце), в стиле оригинала.

## Ассеты
- Цифры времени: реконструкция v0.3 (`art/time/*`), 7 сегментов, в обычном режиме с погашенными сегментами.
- Надписи и мелкие цифры набираются шрифтом **Orbitron** (OFL 1.1), тем же, что в оригинале.
  Кириллицы в Orbitron нет. Её рисуем в стиле Orbitron (буквы, видимые в DM, по референсу) и собираем
  шрифт «Segment Cyr» (OFL, без имени «Orbitron») в `fonts/`.
- Погода: около 12 уникальных иконок, разложенных по 29 номерам системы (таблица соответствия в конфиге).

## Поведение
- Только 24h.
- Язык: RU по умолчанию. Набор картинок выбирается через `getLanguage()` из `@zos/settings`, если нужной
  локали нет — берётся единственный доступный.
- Раскладка фиксированная.
- Тапы открывают системные приложения: пульс, активность, погода, будильник, календарь (что доступно).

## AOD (вариант D1)
- Основа — раскладка обычного режима.
- Убраны: температура, иконка погоды, будильник, секунды, батарея справа от времени.
- Дата и день недели сверху, подняты выше, чтобы вокруг времени было больше воздуха.
- Время залитыми сегментами v0.3 без погашенных сегментов, #B9B9BE, высота около 80 px (запас под лимит).
- Калории, шаги и пульс одной строкой. Батарея на месте дистанции.
- Худший случай должен укладываться в ≤ 9,5% круга. Пересчитать после перехода на Orbitron.
- Пульс в AOD показывает последнее измеренное значение. Это принято.

## Этапы
1. ✅ Каркас и прототип только со временем + AOD, `.zab` собирается.
2. ✅ Макеты 001–003. Выбран AOD D1.
3. Кириллица «Segment Cyr» (задание 004), точная раскладка обычного режима по оригиналу.
4. Установка на часы, проверка.
5. Полный набор: дата, месяц, день недели, метрики, погода, статусы, тапы.
