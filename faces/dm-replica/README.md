# DM Replica

Восстановленная копия циферблата **DM** для Amazfit Active Max (Zepp OS 5.0), сделанная для личного использования.

## Об оригинале

Оригинальный циферблат **DM** («Everything you need on a black screen») создал автор **larrabee777**
для Amazfit T-Rex 2. Мне очень понравилась эта работа, но для Active Max её не существует, а исходники с
часов достать нельзя. Поэтому внешний вид восстановлен по скриншотам: цифры и компоновка перерисованы
вручную, исходные файлы автора не использовались.

К сожалению, мне не удалось найти никакой информации об авторе и способа с ним связаться, чтобы спросить
разрешения. Если вы larrabee777 или знаете, как с ним связаться, — напишите, пожалуйста (issue в этом
репозитории). **По первому запросу автора эта копия будет удалена.**

Проект некоммерческий: копия не публикуется в магазине Zepp, готовые `.zab` не распространяются.

Все права на дизайн DM принадлежат его автору.

## Сборка

Живёт внутри монорепо `amazfit-watchfaces` в каталоге `faces/dm-replica`:

```bash
npm run build -w faces/dm-replica
```

Шрифт надписей — Orbitron (SIL OFL 1.1, The League of Moveable Type), кириллица дорисована.
