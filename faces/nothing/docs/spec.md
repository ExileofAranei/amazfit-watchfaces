# NOTHING — спецификация

Точечный цифровой циферблат в духе Nothing для Amazfit Active Max (480×480). Своё оформление, не копия.
Обычный экран и AOD выглядят одинаково. Общая архитектура описана в `../../../docs/architecture.md`.

## Время
- Каждая цифра стоит в своей рамке 8×12 точек. Штрих шириной 2 точки, внутренние просветы 4 точки
  по ширине и 3 по высоте. Фона у цифр нет: рисуются только горящие точки.
- Ширина рамки чётная, поэтому ножка «1» и «7» шириной 2 точки стоит ровно по центру.
  Основание «1» занимает колонки 1–6, вровень с флажком.
- Хвосты «6» и «9» на колонку короче рамки.
- Шаг сетки 9 px, радиус точки 3.42 px (0.38 шага). Рамка цифры 72×108 px, рамка двоеточия 2×12 точек (18×108 px).
- Строка HH:MM — одна сетка: между соседними рамками ровно одна пустая колонка, в том числе
  по обе стороны двоеточия. Строка 342×108 px по центру экрана.
- Двоеточие — два квадрата 2×2, по 3 пустых ряда сверху и снизу.
- Один цвет `#F2F2F2`.
- Единственный источник глифов — `art/glyphs.ts`. После правки: `npm run glyphs -w faces/nothing`.

## Слоты
- Над временем и под ним по слоту (верх строки на y = 38 и y = 426, как было в SEGMENT). В редакторе для каждого:
  «Выкл.», шаги, пульс, заряд в процентах. По умолчанию оба выключены.
- Числа набраны Orbitron, цвет как у времени.

## AOD
- Лимит Zepp — 10% площади круга. Худший случай с двумя слотами (`08:08`, пульс, шаги) — 8,5%.
