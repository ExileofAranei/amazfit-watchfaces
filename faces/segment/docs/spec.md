# SEGMENT — спецификация

Копия циферблата **DM** (автор larrabee777, Amazfit T-Rex 2) для Amazfit Active Max.
Циферблат предназначен для личного использования и устанавливается через QR-код в приложении Zepp. По первому
запросу автора копия удаляется. Общая архитектура описана в `../../../docs/architecture.md`.

## Дизайн
- Обычный режим — **копия DM один в один**: компоновка, размеры, цвета и шрифт как в оригинале.
- Своё рисуем только для иконок. Огонь, следы, сердце, молния и будильник — залитые силуэты в стиле оригинала. Погода — залитые силуэты (набор C, задания 008–009 дизайнера), жёлтый только у солнца.

## Ассеты
- Цифры времени: реконструкция v0.3 (`art/time/normal`), 7 сегментов, в обычном режиме с погашенными сегментами.
- Надписи и мелкие цифры набираются шрифтом **Orbitron** (OFL 1.1), тем же, что в оригинале.
  Кириллицы в Orbitron нет. Её рисуем в стиле Orbitron (буквы, видимые в DM, по референсу) и собираем
  шрифт «Segment Cyr» (OFL, без имени «Orbitron») в `fonts/`.
- Погода: 14 уникальных иконок, разложенных по 29 номерам системы (`art/icons/weather-map.json`).

## Поведение
- Только 24h.
- Одна сборка выбирает язык через `getLanguage()` из `@zos/settings`. При русском языке часов названия месяцев и дней недели русские, при любом другом — английские. Названия выводятся полностью на основном экране.
- Расстояние отображается в километрах с подписью `КМ` или `km`.
- Раскладка фиксированная.
- Тапы открывают системные приложения: пульс, активность, погода, будильник, календарь (что доступно).

## AOD

- По центру чёрного экрана время HH:MM из круглых точек #B9B9BE. Матрица 8×12, двойные вертикали, высота 128 px.
- Строка занимает 429 px. Между цифрами каждой пары 4 px, по обе стороны двоеточия по 20 px.
- В редакторе на фоне точечного времени два независимых слота, по центру на y = 38 и y = 426 (верх видимой строки). В каждом можно выбрать «Выкл.», пульс, шаги или заряд в процентах. Оба по умолчанию выключены.
- Бюджет горящих пикселей с учётом сглаживания составляет 10% площади круга. [Требования Zepp](https://docs.zepp.com/docs/designs/specifications/screen-off-mode/)

## Этапы
1. ✅ Каркас и прототип только со временем + AOD, `.zab` собирается.
2. ✅ Макеты 001–003. Выбран AOD D1.
3. Кириллица «Segment Cyr» (задание 004), точная раскладка обычного режима по оригиналу.
4. Установка на часы, проверка.
5. Полный набор: дата, месяц, день недели, метрики, погода, статусы, тапы.
